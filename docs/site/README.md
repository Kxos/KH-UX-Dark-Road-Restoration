# Project portal (Re-Union X)

The portal is `docs/index.html`, served by GitHub Pages at
<https://kxos.github.io/KH-UX-Dark-Road-Restoration/>. It is static: edit, commit, push, and the page updates
within a minute or two. Nothing to build.

| File | Purpose |
|---|---|
| `../index.html` | The page: all the sections (Home, Status, Help us, Play, Notices, Gallery, Credits) and the footer |
| `style.css` | The game-like look (CSS and hand-drawn SVG only) |
| `app.js` | Tabs (by address hash, e.g. `#status`), status list, gallery and lightbox |
| `status.json` | **The facts of the Status section** |
| `gallery.json` + `gallery/` | **The Gallery** |

After changing `style.css` or `app.js`, raise the `?v=N` after their names in `index.html`, so browsers do
not mix a cached old file with the new page.

The Notices (`docs/notices/`) are generated by `node server/export-notices.js`: never edit them by hand.

## Updating the status

Edit `status.json`. Each area:

```json
{ "name": "Story quests", "state": "done", "detail": "One or two sentences.", "done": 979, "total": 979, "unit": "quests" }
```

- `state`: `done` (group «Works today»), `progress` («In progress») or `missing` («Not there yet»).
- `done` / `total`: fill of the bar; with `unit` the row also shows «done/total unit», without it a percentage
  (hidden for `done` rows).
- The meter at the top counts the areas in state `done`.
- Also update `updated` and, when it changes, `summary`. The «Where we are» rows of the Home section are plain HTML
  in `index.html`.

## Adding screenshots to the gallery

1. Put the images in `docs/site/gallery/` (PNG/JPG/WebP, ideally 16:9, under ~500 KB each; e.g. 1280x720 JPG).
2. List them in `gallery.json`, in display order:

```json
[
  { "file": "story-quest-979.jpg", "caption": "Quest 979, the final battle" },
  { "file": "shop-banner.jpg", "caption": "The Shop with an original banner" }
]
```

With an empty list (`[]`) the page shows «Screenshots coming soon». Click an image to open the lightbox
(arrows / Esc on the keyboard).

## Rules

No Square Enix / Disney assets in the site itself (logos, art, fonts, textures, extracted images): the look is
made with CSS. Gallery screenshots are the user's own captures of the running game.
