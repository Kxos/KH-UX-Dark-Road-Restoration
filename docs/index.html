The project

Kingdom Hearts Union χ closed its servers in May 2021. The app that is still in the stores is only a theater mode: the game itself is gone.

Re-Union X brings it back as a game you can play on your own computer. The original 4.3.1 Android client runs unmodified; everything it used to ask the official servers is answered by a new server written from scratch, from what the client itself tells us and from data preserved by the community.

Where we are

  • WORKSStory quests 1-979 with the original maps, cutscenes and music
  • WORKSMedals, Level Up, Evolve, Shop with the original banners, Moogle Shop, missions
  • IN PROGRESSAbout 88 enemy families still lack their original graphics
  • MISSINGEvents, raids, Coliseum, Union Cross and PvP

Honest status: this is a work in progress. It runs on an Android emulator for Windows, the setup is still long and technical, and you should expect bugs and crashes.

How you can help

Most of the game was downloaded from the servers after install and was never inside the app. Part of it is now lost from every public archive. If you played KHUx, your old phone or backup may hold the missing pieces.

What we are looking for

  • MOST WANTEDA files/r/ folder or misc.mp4 from a KHUx install (Global or JP, any version), or a device backup that contains one
  • MOST WANTEDGraphics of about 88 enemy families of quests 526-979: Gearbits, Flappy Bugs, Cy-Bugs, King Candy, Jafar, Dragon Maleficent, Darkness, Ephemer & Skuld...
  • EVENTSScreenshots, videos, rules and rewards of events, raids, Coliseum, Union Cross and PvP
  • TECHNICALNetwork captures of the game talking to the official servers
  • ANYTHINGYour own screenshots and videos of any screen of the game, any year

Where a file could still be

On Android the downloaded data lived in Android/data/com.square_enix.android_googleplay.khuxww/files/r/ (JP: the same path with the JP package). Old phones, SD cards, Titanium/adb backups and PC copies of the phone are all worth a look. Do not post game files publicly: open an issue and we will agree on a private way to share them.

How to play

Today the setup is long and complex: an Android emulator on Windows, the original client that you must obtain yourself, the server of this project and a few network settings. When the work is finished it will be simplified with a launcher.

This is a work in progress: expect bugs, crashes and screens that are not there yet. No game files are distributed here.

Setup guide

Found a bug?

Report it with the bug form on GitHub. A good report has:

  • What you did, step by step, and what you expected
  • What happened instead (error popup, crash, wrong screen)
  • Where: screen, quest number, medal or banner involved
  • A screenshot or video, if you can
  • The server log around the moment of the problem
  • Your setup: emulator and version, Windows version, project version (commit)
