# Shop sub-project 3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** seasonal banners on the real calendar, Limited quests with tickets after the unlock, Catalog with tabs per game year and
Filters panel, one old banner pinned in the Shop, Notices updated.

**Architecture:** the choice of the list stays in `server/gacha.js shopBanners`, which receives two new inputs
(active seasonal banners and pinned banner) already computed by pure modules: `server/gacha-seasons.js` (table and windows) and
new functions of `gacha.js` (pinnability, ticket thresholds). `server.js` passes the real now and `player.gacha.pinned`,
exposes the WebView routes for pinning and search, and restricts the Limited quests. The pages remain HTML generated by
`gacha.js` with inline JavaScript.

**Tech Stack:** Node.js (server without external dependencies), tests as scripts `node server/test-*.js` with `check()`;
Python generator `recon/tools/make_banner_catalog.py` with `recon/tools/test_make_banner_catalog.py`.

**Spec:** `docs/superpowers/specs/2026-10-20-shop-sp3-design.md` (approved by the user on 20-10-2026).

## Global Constraints

- Original client unmodified: only server responses, served master, WebView pages.
- Game texts in English; code and comments like the surrounding code (Italian), UTF-8 without BOM.
- Never two payType 8 currencies in the same list; precedence season > pinned > rotation (spec 4.2).
- `SHOP_MAX` stays 20 and includes seasonal and pinned banners.
- Season date = `realNow()` (real server time, `-RealNow <ISO>` in tests), windows by month/day.
- Closing the WebView does not reload the Shop: every action that changes the Shop says «Leave and re-enter the Shop
  to see it.»
- After every change to `server/master_data` or to the served master: bump the revision in the 4 session scripts.
- Commit + push at every task (`git -c safe.directory=* ...`, `git commit -F <file>`, messages in Italian with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`, `git pull --rebase` before the push).
- Bench: only one script at a time; SKIP on dialogues; taps only while the game is alive.

## Review Focus

1. Windows straddling the year (`newyear` 22/12-17/01, `holiday` 07/12-06/01): 31/12 and 05/01 are inside,
   18/01 outside; the edition of B0219 (start 22/12/2017) is 2017-18, not the 2017 of the New Year's Deals. Test in Task 1.
2. Pinned banner that is also in the rotation week or in the season (does not happen by construction, but a
   save may have it): a single tile, never duplicate `drawMedalTypeId`s (the client rejects them). Test in Task 2.
3. `player.gacha.pinned` pointing to a rowId that has disappeared or is no longer pinnable (catalog regenerated): no crash, the
   tile does not appear, the Catalog shows it as not pinned. Test in Task 3.
4. Search by medal with upper case, spaces, «[+]», «★» and names with U+FFFD (I-150): «roxas» finds the banners of
   «HD Roxas», «Roxas [+]»; an empty string does not filter. Test in Task 5.
5. Countdown: the seasonal banners have the end of the window, the pinned one none, and `shopLeaveWeeks` does not
   count them as rotation banners leaving. Test in Task 2.
